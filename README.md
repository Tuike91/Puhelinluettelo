# Puhelinluettelo

Puhelinluettelo-sovellus, joka on tehty osana
Full Stack Open -kurssin harjoituksia.

Sovelluksessa voi:
- lisätä henkilöiden puhelinnumerot
- hakea henkilöitä nimellä
- poistaa henkilöitä
- päivittää olemassa olevan henkilön puhelinnumeron
- nähdä ilmoituksen toiminnoista

Henkilötiedot tallennetaan db.json tiedostoon JSON Serverin avulla
ja palvelimen kanssa kommunikoidaan Axios-kirjaston avulla.

## Teknologiat

- React
- JavaScript
- Vite
- Axios
- JSON Server
